# 화면설계흐름

- 기준 문서: `ebook-rental-erd.md`
- 작성일: 2026-06-11
- 목적: ERD 기준으로 화면마다 필요한 기능과 클릭 시 이동 흐름을 간단히 정리한다.
- 범위: 회원/비회원 화면, 관리자 화면, 주요 알림 흐름

## 1. 전체 핵심 흐름

```text
비회원
-> 메인/홈
-> 도서 목록/검색
-> 도서 상세
-> 로그인 또는 회원가입

회원
-> 로그인
-> 도서 상세
-> 무료 대여 또는 유료 결제
-> 전자책 뷰어
-> 이어보기/북마크/TTS
-> 반납
-> 리뷰/통계/챌린지 반영

관리자
-> 관리자 대시보드
-> 회원/도서/대여/결제/신고/공지/쿠폰/챌린지/희망도서/도서관/통계 관리
```

## 4. 주요 상세 흐름도

### 4.1 도서 대여 흐름

```text
U-001 메인/홈
-> U-006 도서 목록 또는 U-007 검색 결과
-> U-008 도서 상세
-> U-009 대여/결제 확인
   -> 무료 도서: 대여 생성
   -> 유료 도서: 결제 + 쿠폰/포인트 적용
-> U-011 전자책 뷰어
-> U-010 내 대여 현황
```

### 4.2 뷰어/반납/리뷰 흐름

```text
U-011 전자책 뷰어
-> 페이지 이동/이어보기 저장
-> 북마크 저장
-> TTS 재생
-> U-010 내 대여 현황
-> 반납
-> U-013 리뷰 작성/수정
-> U-008 도서 상세 리뷰 반영
```

### 4.3 출석/포인트/쿠폰/챌린지 흐름

```text
U-014 마이페이지
-> U-016 출석체크
-> 포인트 적립
-> 챌린지 진행 반영
-> 챌린지 달성
-> 포인트 또는 쿠폰 보상
-> U-017 포인트/쿠폰 내역
```

### 4.4 희망도서 흐름

```text
U-007 검색 결과 없음
-> U-022 희망도서 신청
-> U-023 희망도서 신청 내역
-> A-011 희망도서 관리
   -> 승인: A-005 도서 등록 -> U-008 도서 상세 연결
   -> 반려: 반려 사유 저장 -> U-019 알림
```

### 4.5 신고 처리 흐름

## 5. 화면 설계 시 공통으로 넣을 상태

| 상태 | 필요한 화면 | 표시 내용 |
|---|---|---|
| 로딩 | 목록, 검색, 결제, 통계 | 데이터를 불러오는 중 |
| 빈 목록 | 검색 결과, 관심 도서, 대여 현황, 신고 내역 | 표시할 데이터 없음 |
| 로그인 필요 | 대여, 즐겨찾기, 리뷰, 신고, 마이페이지 | 로그인 후 이용 가능 |
| 권한 없음 | 관리자 화면 | 관리자만 접근 가능 |
| 성공 | 가입, 대여, 결제, 신고, 저장 | 처리 완료 메시지 |
| 실패 | 결제, 저장, 신고 제출 | 실패 사유와 재시도 버튼 |
| 제재 회원 | 로그인, 대여, 리뷰/신고 | 이용 제한 안내 |

## 6. ERD 기준 참고 사항

| 항목 | 화면 설계 반영 |
|---|---|
| 회원 삭제 상태 | 별도 탈퇴 상태 화면보다는 삭제/탈퇴 확인 정책 필요 |
| 등급 변경 이력 | 등급 이력 화면은 만들지 않고 현재 등급만 표시 |
| 추천 로그 | 추천 이력 화면은 만들지 않고 같은 작가/카테고리 추천만 표시 |
| TTS 마지막 위치 | TTS 위치 저장 화면은 만들지 않음 |
| 채팅 | ERD에서 제외. 문의 채팅 화면은 이번 흐름도에서 제외 |
| 현재 연체 여부 | 저장값이 아니라 반납일/반납 예정일 기준으로 계산해서 표시 |
| 리뷰 수/즐겨찾기 수 | 기본 화면에서는 집계값으로 표시 |

## 7. 확인 필요

| 항목 | 확인할 내용 |
|---|---|
| 결제수단 | `CARD`, `KAKAO`, `NAVER`, `BANK` 중 실제 허용 범위 확정 필요 |
| 쿠폰 혜택값 | `benefit_value`가 일수, 금액, 비율 중 무엇인지 쿠폰 유형별 정의 필요 |

| 회원 물리 삭제 | 회원 삭제 시 대여/리뷰/결제 이력 처리 정책 결정 필요 |
