## 2. U-001 메인/홈

### 화면 구성

| 영역 | 표시 내용 |
|---|---|
| 헤더 | 공통 User 헤더 |
| 메인 배너 | 서비스 소개 문구, 대표 도서 이미지, `도서 둘러보기` 버튼 |
| 통합 검색 | `어떤 책을 찾고 계신가요?` 검색창 |
| 카테고리 | 활성 대분류 8개와 `전체보기` |
| 추천 도서 | 회원은 관심 카테고리 중심, 비회원은 공통 추천 도서 |
| 컬렉션/이벤트 | 활성 시리즈/이벤트 컬렉션과 컬렉션별 대표 도서 5~6개 미리보기 |
| 신간 도서 | 최신 등록순 도서 카드 |
| 베스트 도서 | 인기순 도서 카드 |
| 무료 도서 | `rentalType = FREE` 도서 카드 |
| 유료 도서 | `rentalType = PAID` 도서 카드 |
| 공지 | 최신 활성 공지 3건 |
| 푸터 | 공통 User 푸터 |

### 버튼과 이동

| 버튼/요소 | 비회원 동작 | 회원 동작 |
|---|---|---|
| `도서 둘러보기` | `U-006` 이동 | 동일 |
| 검색 버튼 | 검색어가 있으면 `U-007` | 동일 |
| 카테고리 | `U-006?categoryId={id}` | 동일 |
| 도서 카드/표지/제목 | `U-008` | 동일 |
| 섹션 `더보기` | 조건이 적용된 `U-006` | 동일 |
| 컬렉션/이벤트 카드 | `U-006?collectionId={id}` 또는 `U-006?section=event` 이동 | 동일 |
| 즐겨찾기 하트 | 로그인 모달 후 `U-003` | 등록/해제 후 현재 화면 유지 |
| 공지 제목 | 공지 상세 모달 | 동일 |

### 상태별 표시

| 상태 | 처리 |
|---|---|
| 비회원 | 로그인/회원가입 버튼 표시 |
| 회원 | 내 서재/알림/마이페이지/로그아웃 표시 |
| 추천 결과 없음 | 베스트 도서로 대체 |

연동 API: `API-BOOK-001`, `API-BOOK-005`, `API-CATEGORY-001`, `API-COLLECTION-001~002`, `API-NOTICE-001`, `API-FAV-001~002`

## 3. U-002 회원가입

### 입력 항목

| 항목 | 필수 | 입력/검증 |
|---|---:|---|
| 아이디 | Y | 영문/숫자 조합, 가입 제출 시 중복 검증 |
| 비밀번호 | Y | 서비스 비밀번호 규칙 표시 |
| 비밀번호 확인 | Y | 비밀번호와 일치, DB 저장 안 함 |
| 이름 | Y | 50자 이하 |
| 이메일 | Y | 이메일 형식, 가입 제출 시 중복 검증 |
| 전화번호 | N | `010-0000-0000` 형식 |
| 생년월일 | Y | 미래 날짜 입력 불가 |
| 성별 | N | 남성/여성/선택 안 함 |

### 버튼과 이동

| 버튼 | 기능 | 결과/이동 |
|---|---|---|
| `가입하기` | 입력 검증 후 회원 생성 | 성공 시 `U-003` |
| `로그인` | 기존 회원 로그인 | `U-003` |
| `취소` | 가입 중단 | `U-001` |

약관 동의는 회원가입 저장 항목에서 제외한다. 푸터의 이용약관 문서 열람만 제공한다.

연동 API: `API-AUTH-001`

| `로그인` | `WITHDRAWN` | 탈퇴 계정 안내, 현재 화면 유지 |
| `로그인` | `DEACTIVATED` | 비활성 계정 안내, 현재 화면 유지 |

| `아이디 찾기` | 클릭 | `U-004` |

연동 API: `API-AUTH-002`

## 6. U-005 비밀번호 재설정(제외)

`api-spec(final).md` 기준 비회원 비밀번호 재설정 API는 final 범위에서 제외한다. 따라서 `U-005`는 active 화면과 이동 흐름에 배치하지 않는다.

| 항목 | 처리 기준 |
|---|---|
| 비회원 비밀번호 재설정 | 제공하지 않음 |
| 로그인 전 비밀번호 분실 | 운영/고객센터 안내 또는 후속 범위에서 별도 정의 |
| 로그인 회원 비밀번호 변경 | `U-015 회원정보 수정`에서 처리 |

연동 API: 없음(제외). 로그인 회원 비밀번호 변경은 `API-ME-003`을 사용한다.
관련 테이블: 없음(제외). 로그인 회원 비밀번호 변경은 `MEMBER` 기준으로 처리한다.

### 화면 구성

| 영역 | 표시 내용 |

| 버튼/요소 | 기능 | 이동/결과 |
|---|---|---|

| 컬렉션/이벤트 조건 | 컬렉션 상세 도서 또는 이벤트 도서 목록 조회 | 현재 화면 목록 갱신 |

| 도서 카드 | 상세 조회 | `U-008` |
| 즐겨찾기 하트 | 비회원은 로그인 유도, 회원은 등록/해제 | 현재 화면 |

컬렉션/이벤트 진입은 `collectionId` 또는 `section=event` 조건으로 표시하며, EVENT 알림 클릭 시에도 같은 목록 조건을 사용한다.

연동 API: `API-BOOK-001`, `API-CATEGORY-001`, `API-COLLECTION-001~002`, `API-FAV-001`, `API-FAV-002`

## 10. U-009 대여/결제 확인

### 공통 표시

도서 표지, 제목, 대여 유형, 대여 기간, 첫 읽기 시작 전 `READY` 상태 안내, 대여 정책을 표시한다.

### 무료 도서

| 버튼 | 기능 | 이동/결과 |
|---|---|---|
| `무료 대여 확정` | `BOOK_RENTAL` 생성 | 성공 모달 후 `U-011` |
| `내 서재에서 보기` | 대여 성공 후 이동 | `U-010` |
| `취소` | 상세로 복귀 | `U-008` |

### 유료 도서

| 영역 | 표시 내용 |
|---|---|
| 결제수단 | 카드 결제만 표시 |
| 쿠폰 | 사용 가능한 회원 쿠폰 목록, 할인 수단으로 적용 |
| 포인트 | 사용 가능 잔액, 결제 차감 수단으로 적용 |
| 금액 | 할인 전 금액, 쿠폰 할인, 포인트 차감, 최종 카드 결제 금액 |
| 동의 | 결제 내용 확인 체크 |

| 버튼 | 기능 | 이동/결과 |
|---|---|---|
| `쿠폰 적용` | 유효 쿠폰 선택 및 할인 계산 | 현재 화면 |
| `포인트 사용` | 사용 포인트 입력 및 차감 계산 | 현재 화면 |
| `결제하기` | 카드 더미 결제 완료 후 대여와 `PAID` 결제 생성 | 성공 시 `U-011` |
| `취소` | 결제 전 중단, 도서 상세 복귀 | `U-008` |

쿠폰과 포인트는 결제수단이 아니다. 100% 쿠폰 또는 포인트 전액 차감으로 최종 카드 결제 금액이 0원이 되어도 유료 대여는 `PAYMENT` row를 저장한다. 결제 완료 전에는 사용자가 중단할 수 있으며, 완료된 `PAID` 결제 row만 저장한다.

연동 API: `API-RENTAL-001`, `API-PAYMENT-001`, `API-COUPON-001`, `API-POINT-001`

희망도서는 후보 단위로 집계하며, 신청 목록은 회원 본인의 개별 신청 상태와 후보 신청자 수를 함께 표시한다. `검토 중`은 후보 상태 `BOOK_REQUEST_CANDIDATE.candidate_status = IN_REVIEW`를 조인해 표시하며 회원별 `BOOK_REQUEST.request_status`에는 저장하지 않는다.

연동 API: `API-REQUEST-002`(`GET /api/v1/me/book-requests`)
관련 테이블: `BOOK_REQUEST_CANDIDATE`, `BOOK_REQUEST`, `BOOK`
