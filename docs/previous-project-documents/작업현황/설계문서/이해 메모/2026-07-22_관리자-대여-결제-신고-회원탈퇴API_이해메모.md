# 관리자 대여·결제·신고·회원 탈퇴 API 이해 메모

작성일: 2026-07-22

API: `API-ME-004 DELETE /api/v1/me`  
목적: 본인 계정을 물리 삭제 없이 `WITHDRAWN`으로 전환한다.  
흐름: 현재 비밀번호 확인 → ADMIN/진행 중 대여 검사 → 상태·탈퇴 일시·사유 저장.  
DB: `MEMBER`, 조회 전용 `BOOK_RENTAL`.  
주의: `READY`/`READING`이 있으면 거절, `OWNED`는 허용하며 대여 행은 바꾸지 않는다.

API: `API-ADMIN-RENTAL-001 GET /api/v1/admin/rentals`  
목적: 관리자가 대여 현황과 읽기 진행률을 조회한다.  
흐름: ADMIN 인증 → query 검증 → page·count 조회 → 연관 데이터 조립.  
DB: `BOOK_RENTAL`, `MEMBER`, `BOOK`, `READING_PROGRESS`, `PAYMENT`.  
주의: `READY`/`READING`/`OWNED`만 조회하며 수정·대여 종료 기능은 제공하지 않는다.

API: `API-ADMIN-PAYMENT-001 GET /api/v1/admin/payments`  
목적: 관리자가 완료 결제와 쿠폰·포인트 차감 정보를 조회한다.  
흐름: ADMIN 인증 → `q`/`from`/`to` 검증 → `PAID` 목록 page 조회 → 금액 상세 조립.  
DB: `PAYMENT`, `BOOK_RENTAL`, `MEMBER`, `BOOK`, `COUPON_USAGE`, `POINT_HISTORY`.  
주의: 취소·환불·복구와 명세에 없는 `memberId` query는 이번 API에 추가하지 않는다.

API: `API-ADMIN-REPORT-001 GET /api/v1/admin/reports`  
목적: 책·리뷰 신고를 처리 화면에서 바로 확인할 수 있게 목록으로 반환한다.  
흐름: ADMIN 인증 → target/status 검증 → BOOK/REVIEW 신고를 정렬·page 조립.  
DB: `BOOK_REPORT`, `REVIEW_REPORT`, `MEMBER`, `BOOK`, `REVIEW`.  
주의: 별도 상세 API를 만들지 않고 목록 행에 신고 내용·신고자·대상 정보를 포함한다.

API: `API-ADMIN-REPORT-002 PATCH /api/v1/admin/reports/{targetType}/{reportId}/status`  
목적: 관리자가 신고 상태·결과를 수동 처리하고 필요 시 리뷰 숨김·계정 정지를 수행한다.  
흐름: ADMIN 인증 → 대상/상태 전이 검증 → 변경·알림·감사 로그를 한 transaction으로 저장.  
DB: `BOOK_REPORT` 또는 `REVIEW_REPORT`, `REVIEW`, `SANCTION_HISTORY`, `MEMBER`, `NOTIFICATION`, `ADMIN_AUDIT_LOG`.  
주의: 자동 조치는 없고, 숨김·`ACCOUNT_SUSPENSION`은 REVIEW의 `DONE` 처리에서만 허용한다.
