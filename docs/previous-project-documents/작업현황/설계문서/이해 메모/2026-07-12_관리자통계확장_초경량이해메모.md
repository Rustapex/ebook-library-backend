# 관리자 통계 확장 — 초경량 이해 메모

작성일: 2026-07-12 (형식: `docs/작업현황/설계문서/2026-07-11_초경량-이해-메모-규칙.md` 기준)

---

- API: API-ADMIN-STAT-001 GET /api/v1/admin/statistics
- 목적: 기간/나이대/추이/환경 지표 통계가 프론트 A-016 요구와 같은 기준으로 집계되게 한다.
- 흐름: AdminStatisticController -> AdminStatisticService -> 각 Repository count/sum/bucket 집계
- DB: MEMBER, BOOK, BOOK_RENTAL, READING_PROGRESS, PAYMENT, REVIEW, BOOK_REPORT, REVIEW_REPORT 조회 중심, 스키마 변경 없음
- 주의: 현재 A-016 그래프는 이벤트 발생량 추이이므로 기본은 실시간 집계이며, 과거 상태 스냅샷 그래프나 성능 문제가 생길 때만 스케줄러/스냅샷을 후속 검토한다.
