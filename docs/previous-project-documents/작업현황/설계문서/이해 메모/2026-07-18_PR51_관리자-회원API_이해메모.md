# 2026-07-18 PR51 관리자 회원 API 이해 메모

## API-ADMIN-MEMBER-002

목적: 관리자 회원 상세의 탭별 이용·신고 이력을 조회한다.
흐름: 탭 값을 검증하고 탭별 DTO와 페이지 조회 결과를 반환한다.
DB: REPORTS는 책 신고·리뷰 신고를 정렬·페이징 가능한 조회 방식으로 통합한다.
주의: 전체 신고 목록을 메모리에 합친 뒤 페이지를 자르지 않고 Swagger 응답 타입을 구체화한다.

## API-ADMIN-MEMBER-003

목적: 관리자 회원 상태·제재를 변경하고 필요하면 수동으로 계정 정지를 해제한다.
흐름: 보호 대상 확인 → 상태 변경 또는 제재 처리 → 감사 로그 기록이다.
DB: JOINED로 직접 전환하면 `current_sanction_id` 연결을 해제한다.
주의: 스케줄러는 범위 제외이며, 수동 복구는 `status=JOINED`와 사유로 수행한다.

## API-ADMIN-MEMBER-004

목적: 관리자가 회원 포인트를 지급·차감한다.
흐름: requestId 재시도 확인 → 대상 잠금·보호·잔액 검증 → 이력·감사 로그를 한 transaction으로 기록한다.
DB: `(member_id, request_id)` UNIQUE와 `balance_after`로 멱등 키와 최초 성공 잔액을 보관한다.
주의: ADMIN·탈퇴·비활성 회원은 거부하고, 재시도는 현재 잔액이 아닌 최초 `balanceAfter`를 반환한다.
