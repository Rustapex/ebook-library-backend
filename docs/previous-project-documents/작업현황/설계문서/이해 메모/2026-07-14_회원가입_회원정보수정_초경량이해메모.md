# 회원가입/회원정보 수정 초경량 이해 메모

작성일: 2026-07-14

API: `API-AUTH-001 POST /api/v1/auth/signup`
목적: 비회원 신규 회원가입
흐름: Body 검증 → loginId/email 중복 확인 → 비밀번호 확인 → 기본 등급 조회 → member 저장
DB: `MEMBER`, `MEMBER_GRADE`
주의: 중복 실패는 409 + 공통 에러 JSON으로 응답한다.

API: `API-ME-001 GET /api/v1/me`
목적: 회원정보 수정 화면 진입 전 기존 정보 채우기
흐름: JWT 인증 → 인증 memberId로 회원 조회 → 수정 화면에 필요한 기본 정보 반환
DB: `MEMBER`, 필요 시 `MEMBER_GRADE`
주의: 다른 회원 ID를 파라미터로 받지 않는다.

API: `API-ME-002 PATCH /api/v1/me`
목적: 로그인 회원 본인의 기본 정보 수정
흐름: JWT 인증 → 회원 조회 → 이메일 중복 확인 → 허용 필드만 변경 → 변경 정보 반환
DB: `MEMBER`
주의: `loginId`, `birthDate`, `role`, `status`는 수정하지 않는다.
