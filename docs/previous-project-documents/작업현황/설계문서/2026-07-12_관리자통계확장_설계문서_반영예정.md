## 반영 대상

`docs/화면흐름도/03-Admin-상세화면설계도.md`의 `A-016 통계 관리` 절.

## 반영 이유

기간 필터, 현재 상태 기준 KPI, 나이대 필터, 그래프 집계 기준, 환경 지표 계산 기준이 문서마다 다르게 해석되지 않도록 프론트/백엔드 계약을 고정하기 위함.

## 반영할 확정 내용 (구현계획 §3.6 기준)

| 항목 | 확정 내용 |
|---|---|
| 그래프/추이 집계 방식 | 대여/결제/완독 추이는 원본 이벤트 시간 컬럼 기준 실시간 bucket 집계(선택지 C 하이브리드). 과거 상태 스냅샷 그래프는 이번 범위에 없음 |
| `admin_statistic` 테이블 | 이번 범위에서는 사용/재도입하지 않음(후속 성능 이슈 시 재검토) |
| 그래프 bucket 기준 | `WEEKLY`=7일 일별, `MONTHLY`=해당 월 일별, `YEARLY`=12개월 월별, `TOTAL`=baseDate가 속한 달까지 최근 12개월 월별 |
| 현재 상태 지표 | 회원 수, 제재 회원 수, 이용 가능 도서 수는 기간 필터와 무관하게 조회 시점의 현재 상태 기준(과거 시점 복원 안 함) |
| 스케줄러 도입 시점 | 이번 범위에 스케줄러 없음. 과거 상태 스냅샷 그래프가 필요해지거나 실시간 집계 성능 문제가 확인되면 후속 도입 |
| 나이대 필터 기준 | `member.birthDate` 기준 만 나이. 리뷰/신고는 "작성자/신고자" 기준(대상자 기준 아님) |
| 환경 지표 계산식 | 탄소 절약량(`carbonSavedKg`) = 완독 수 × 2kg, 나무 보호량(`treeSavedCount`) = 완독 수 × 0.04그루. DB 저장 없이 응답 시 계산 |

## 반영 방식

화면흐름도에는 화면과 API 계약에 필요한 집계 기준(위 표)만 적는다. Repository/쿼리/테스트 절차 같은 구현 상세는 구현계획 문서와 Swagger/Postman 체크리스트에 그대로 둔다.
