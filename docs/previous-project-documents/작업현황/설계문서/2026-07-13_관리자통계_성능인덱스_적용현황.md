# 관리자 통계 성능 인덱스 — 적용현황 추적

작성일: 2026-07-13
근거: `docs/작업현황/2026-07-12_관리자API후속작업_구현계획.md` §3
대상 SQL: `src/main/resources/관리자통계_성능인덱스.sql`

`spring.sql.init.schema-locations`/`data-locations`가 `schema.sql`/`data.sql`로 고정돼 있어 이 SQL은 자동 실행되지 않는다. 각 개발자가 자신의 로컬 DB에, 그리고 필요 시 팀 공유 DB에 수동으로 적용해야 한다. 이 문서는 "적용 여부"만 추적하며, 실제 적용 행위 자체는 이번 작업 범위가 아니다.

## 인덱스 목록

| 인덱스명 | 대상 테이블.컬럼 |
|---|---|
| `idx_book_rental_created_at` | `book_rental.created_at` |
| `idx_reading_progress_completed_at` | `reading_progress.completed_at` |
| `idx_review_status_created_at` | `review(status, created_at)` |

## 적용 방법 (참고)

```powershell
# ABC 데이터베이스에 접속한 MySQL 클라이언트에서 실행
mysql -u <user> -p ABC < "src/main/resources/관리자통계_성능인덱스.sql"
```

적용 후 `SHOW INDEX FROM book_rental;` 등으로 인덱스 생성 여부를 확인하고, 위 표에 적용일/실행자를 기록한다.
