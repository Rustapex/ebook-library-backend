## 2026-07-02 / 2-5 / `src/main/java/com/acorn/abc/book/service/BookService.java:236-245`

- `normalizeSort`: 잘못된 `sort` 값을 `"latest"`로 조용히 fallback하던 로직을 제거하고, `latest`/`title`/`popular` 외 값이면 `throw new BusinessException(ErrorCode.VALIDATION_ERROR)`로 변경.
- 방식: A안(`BusinessException(VALIDATION_ERROR)`) 채택. 같은 파일의 `normalizeRentalType`(225-234행)과 동일한 패턴이라 `GlobalExceptionHandler`/`build.gradle` 무수정.
- 근거는 코드에 인라인 주석으로 남김. `.\gradlew.bat compileJava` 통과 확인. 기존 테스트 중 `sort` 관련 테스트 없어 회귀 없음(확인됨).
- 영향: 지금까지 오타/잘못된 `sort` 값을 보내던 요청이 있었다면 200(latest 처리) → 400(`VALIDATION_ERROR`)으로 응답이 바뀜.
