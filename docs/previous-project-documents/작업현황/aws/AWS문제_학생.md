## 6. 클라우드 컴퓨팅 서비스 유형에 대해서 서술하시오

<details>
<summary>답 보기</summary>

## 7. 클라우드 컴퓨팅의  주요 특징을 서술하시오

<details>
<summary>답 보기</summary>

온디맨드 : 사용자는 필요한 만큼 자원을 요청하고 언제든지 자원을 추가하거나 줄일 수 있음
유연성과 확장성:  수요에 따라 자원을 자동을 확장하거나 축소할 수 있어 비지니스 환경에 유연하게 대응
비용효율성: 사용한 만큼만 지불함 
            자체 서버나 인프라를 구축하고 유지하는데 드는 비용 절감
인터넷기반: 클라우드 서비스는 인터넷을 통해 제공되며, 사용자는 언제 어디서나 자원에 접근가능
관리의 용이성:  클라우드는 제공업체가 인프라를 관리함으로 사용자는
               서버관리, 보안, 백업, 유지보수에 신경쓸 필요 없다

</details>

## 8. CloudFront 란?   ( s3 버킷의 내용을 전세계에 	빠르게 배포할 수 있는 서비스 )

<details>
<summary>답 보기</summary>

컨텐츠(파일, 동영상 등)를 빠르게 전송하게 해주는 서비스
 컨텐츠를 전송 받는 성능을 향상시키기 위해 사용

전세계 곳곳에 컨텐츠(파일, 동영상)의 복사본을 저장해놓을 수 있는 임시 저장소를 구축한다.
사용자가 컨텐츠를 전송받고 싶을 때, 가장 가까운 임시 저장소에서 컨텐츠를 가져오면 훨씬 속도가 빨라진다.

</details>

## 9. aws vpc란?  ( Ec2생성시 기본적으로  vpc가 제공되었다)

<details>
<summary>답 보기</summary>

AWS VPC는 AWS 클라우드 안에서 사용자 전용 네트워크를 만들 수 있는 서비스이다
네트워크를 논리적으로 분리하여 구성할 수 있으며, 서브넷, ==라우팅 테이블==, 인터넷 게이트웨이 등을 설정할 수 있다

VPC의 구성요소 를 쓰시오
서브넷 (Subnet)	VPC 안에서 나누어진 작은 네트워크 영역 (퍼블릭/프라이빗으로 나눔)
==라우팅 테이블==	트래픽이 어디로 가야 할지 결정하는 표
인터넷 게이트웨이 (IGW)	VPC 내부의 퍼블릭 서브넷이 인터넷과 통신할 수 있도록 해줌
==NAT 게이트웨이== / 인스턴스	프라이빗 서브넷에서 인터넷으로 나갈 수 있게 해줌 (외부에서 접근은 안 됨)
보안 그룹	인스턴스 수준의 방화벽 (들어오고 나가는 포트/트래픽 제어)
==네트워크 ACL==	서브넷 수준의 방화벽 =>DDoS나 악성 IP 대역 차단  , 특정 트래픽을 선별적으로 차단해야 할 때	예: 특정 국가 IP 대역이나 비인가 포트 차단

</details>

## 11. EC2 인스턴스  구매옵션  (수업시간에는 온디멘드 인스턴스 사용함)

<details>
<summary>답 보기</summary>

1) 온디맨드 인스턴스	가장 기본적인 방식. 필요할 때 인스턴스를 즉시 생성하고, 사용한 시간만큼만 비용 지불	 비싸지만 유연함	테스트, 단기 작업, 초기 개발 환경
2) 리저브드 인스턴스 (Reserved Instance)	1년 또는 3년 단위로 장기간 예약 구매. 높은 할인율 제공	  최대 75% 절감 가능	고정적이고 장기적인 워크로드 (예: 상시 운영 서버)
3) 스팟 인스턴스 (Spot Instance)	AWS의 남는 컴퓨팅 자원을 경매 방식으로 저렴하게 제공. 언제든 종료될 수 있음	 매우 저렴 (최대 90% 할인 가능)	중단돼도 되는 비정기성 작업 (예: 빅데이터 분석, 배치 작업)
4) ==전용 호스트== (Dedicated Host)	물리 서버 전체를 한 고객 전용으로 제공. 라이선스 제어나 보안 요구가 높은 경우 사용	  매우 비쌈	특수한 보안 요건, 소프트웨어 라이선스 요구

</details>

## 15. HTTP란?

<details>
<summary>답 보기</summary>

HTTP (HyperText Transfer Protocol)
  “웹에서 데이터를 주고받는 규칙(프로토콜)”

웹브라우저 → 서버로 요청
서버 → 웹브라우저로 응답
=>데이터가 “평문(암호화 안 됨)”으로 전송됨


==HTTPS== (HyperText Transfer Protocol Secure)
  HTTP + 보안(암호화)

데이터를 전송할 때 TLS/SSL로 암호화 해서
중간에서 보더라도 내용을 알 수 없게 만듭니다.

</details>
