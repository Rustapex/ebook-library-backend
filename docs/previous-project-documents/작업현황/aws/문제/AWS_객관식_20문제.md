# AWS 객관식 문제 20선

각 문항에서 가장 알맞은 답 하나를 고르세요.

1. 한 리전 내 여러 가용 영역(AZ)에 EC2 인스턴스를 분산 배치하는 주된 목적은 무엇인가?
   - ① 인스턴스의 공인 IP를 고정하기 위해
   - ② 단일 데이터센터 장애의 영향을 줄이기 위해
   - ③ 모든 트래픽을 하나의 서버로 모으기 위해
   - ④ S3 버킷을 자동으로 암호화하기 위해

2. 주문 완료 시에만 실행되는 이미지 변환 코드를 운영하려 한다. 서버 운영 부담과 유휴 시간 비용을 줄이려면 가장 적합한 서비스는 무엇인가?
   - ① Amazon EC2
   - ② AWS Lambda
   - ③ Amazon RDS
   - ④ Elastic IP

3. 여러 AWS 계정에서 특정 S3 버킷의 보고서만 읽도록 허용하려고 한다. 버킷 자체에 적용하는 리소스 기반 권한 설정으로 가장 적합한 것은 무엇인가?
   - ① 보안 그룹
   - ② IAM 사용자 그룹
   - ③ S3 버킷 정책
   - ④ 라우팅 테이블

4. 웹 서버 세 대가 동일한 애플리케이션을 제공한다. 특정 서버의 장애에도 요청을 정상 서버로 보내고 부하를 분산하려면 무엇을 앞단에 두어야 하는가?
   - ① Amazon SES
   - ② Elastic Load Balancing
   - ③ Amazon S3
   - ④ NAT Gateway

5. 개발자에게 `project-a` 버킷의 객체 조회 권한만 주려고 한다. IAM 설계 원칙으로 가장 적절한 것은 무엇인가?
   - ① 모든 AWS 서비스에 관리자 권한을 부여한다.
   - ② 필요한 버킷과 읽기 작업만 허용하는 정책을 부여한다.
   - ③ 루트 사용자 자격 증명을 공유한다.
   - ④ 보안 그룹 인바운드 규칙으로 S3 권한을 제어한다.

6. 다음 중 클라우드 서비스 모델과 예시의 연결이 가장 적절한 것은 무엇인가?
   - ① IaaS - Amazon EC2
   - ② PaaS - Elastic IP
   - ③ SaaS - VPC
   - ④ IaaS - Amazon SES

7. 서울 리전에 있는 S3의 정적 콘텐츠를 전 세계 사용자에게 더 낮은 지연 시간으로 제공하려 한다. 가장 적합한 서비스는 무엇인가?
   - ① AWS CloudFront
   - ② AWS IAM
   - ③ Amazon RDS
   - ④ Amazon EventBridge

8. VPC의 서브넷을 퍼블릭 서브넷으로 만들기 위한 조건으로 가장 알맞은 것은 무엇인가?
   - ① 라우팅 테이블에 인터넷 게이트웨이(IGW)로 가는 경로가 있다.
   - ② 보안 그룹에 데이터베이스 포트가 열려 있다.
   - ③ NAT Gateway가 반드시 두 개 이상 있다.
   - ④ S3 버킷 정책에 허용 규칙이 있다.

9. 외부에서 직접 접속할 수 없는 프라이빗 서브넷의 EC2가 운영체제 업데이트를 내려받아야 한다. 일반적인 구성으로 가장 적절한 것은 무엇인가?
   - ① 프라이빗 서브넷의 라우팅을 NAT Gateway로 연결한다.
   - ② 모든 프라이빗 EC2에 Elastic IP를 할당한다.
   - ③ 인스턴스에 인터넷 게이트웨이를 직접 연결한다.
   - ④ S3 버킷에 공용 읽기 권한을 부여한다.

10. 보안 그룹(Security Group)과 네트워크 ACL의 설명으로 가장 적절한 것은 무엇인가?
   - ① 보안 그룹은 인스턴스 수준에서 적용되고, 네트워크 ACL은 서브넷 수준에서 적용된다.
   - ② 보안 그룹은 S3 버킷에만 적용되고, 네트워크 ACL은 IAM 사용자에만 적용된다.
   - ③ 둘 다 애플리케이션 로그를 수집하는 서비스다.
   - ④ 둘 다 DNS 레코드를 관리한다.

11. 예측하기 어려운 단기 개발·테스트 환경에서, 장기 약정 없이 필요한 시간만 사용하려면 어떤 EC2 구매 옵션이 적합한가?
   - ① 온디맨드 인스턴스
   - ② 리저브드 인스턴스
   - ③ 전용 호스트
   - ④ 스팟 인스턴스

12. 언제든 중단되어도 재시작 가능한 대규모 야간 배치 작업의 비용을 줄이려 한다. 가장 적합한 EC2 구매 옵션은 무엇인가?
   - ① 온디맨드 인스턴스
   - ② 리저브드 인스턴스
   - ③ 스팟 인스턴스
   - ④ 전용 호스트

13. 3년간 24시간 실행될 것으로 예상되는 핵심 업무 서버의 컴퓨팅 비용을 낮추고 싶다. 가장 먼저 검토할 옵션은 무엇인가?
   - ① 리저브드 인스턴스
   - ② 스팟 인스턴스
   - ③ Elastic IP
   - ④ CloudFront

14. EC2 인스턴스를 중지했다가 시작해도 외부에서 사용하는 IP 주소가 바뀌지 않게 하려 한다. 가장 적합한 것은 무엇인가?
   - ① Elastic IP
   - ② Auto Scaling Group
   - ③ EventBridge Rule
   - ④ S3 Lifecycle Rule

15. 결제 서비스가 `Payment Requested` 이벤트를 발행하면, 조건에 맞는 이벤트만 골라 후속 처리 서비스로 전달하려 한다. 이벤트 버스와 규칙 기반으로 이를 구현하는 서비스는 무엇인가?
   - ① Amazon EventBridge
   - ② Elastic Load Balancing
   - ③ Amazon SES
   - ④ Amazon RDS

16. 다음 EventBridge 규칙이 `source` 값으로 `com.acorn.payment`를 필터링한다면, 이 규칙을 만족하는 이벤트는 무엇인가?
   - ① `source: com.acorn.payment`, `detail-type: Payment Requested`
   - ② `source: com.acorn.shipping`, `detail-type: Payment Requested`
   - ③ `source: com.acorn.payment`, `detail-type: Inventory Updated`이지만 source 값이 없는 이벤트
   - ④ source 필드가 없는 모든 이벤트

17. 데이터베이스 서버 설치, 백업, 확장, 복구 같은 운영 부담을 줄이면서 관계형 데이터베이스를 사용하려 한다. 가장 적합한 서비스는 무엇인가?
   - ① Amazon RDS
   - ② Amazon S3
   - ③ AWS IAM
   - ④ Amazon CloudFront

18. HTTP와 HTTPS의 차이를 가장 정확히 설명한 것은 무엇인가?
   - ① HTTPS는 TLS/SSL을 사용해 전송 데이터를 보호하는 HTTP이다.
   - ② HTTPS는 오직 사설망에서만 사용할 수 있다.
   - ③ HTTP는 파일 저장 서비스이고 HTTPS는 데이터베이스 서비스다.
   - ④ HTTPS는 로드 밸런서 없이만 사용할 수 있다.

19. 회원 가입 인증 메일과 비밀번호 재설정 메일을 대량 발송하려 한다. 가장 적합한 AWS 서비스는 무엇인가?
   - ① Amazon SES
   - ② Amazon S3
   - ③ AWS VPC
   - ④ Amazon EC2 Auto Scaling

20. 다음 요구 사항을 모두 만족하는 설계로 가장 적절한 것은 무엇인가? “인터넷 사용자는 웹 서버에 접근할 수 있어야 하고, 데이터베이스는 인터넷에서 직접 접근할 수 없어야 하며, 웹 서버와 DB는 같은 VPC에서 통신해야 한다.”
   - ① 웹 서버는 퍼블릭 서브넷에, DB는 프라이빗 서브넷에 두고 필요한 보안 그룹 규칙만 허용한다.
   - ② 웹 서버와 DB를 모두 퍼블릭 서브넷에 두고 모든 포트를 허용한다.
   - ③ 웹 서버와 DB를 서로 다른 리전에 두고 IAM 정책만 설정한다.
   - ④ DB를 S3 버킷으로 교체하고 CloudFront를 연결한다.
