<details>
<summary>답 보기</summary>

정답:
==테스트==를 자동화하면 코드를 빠르게 검증할 수 있어, 버그를 조기에 발견하고 전체 품질을 향상시킬 수 있다. 개발 속도도 향상된다.

</details>

## 9. I/CD를 도입했을 때 개발팀이 얻을 수 있는 이점을 서술하시오.

<details>
<summary>답 보기</summary>

==배포== 자동화로 시간 절약
→ 빌드, ==테스트==, ==배포== 과정을 자동화하여 개발자가 수동으로 처리할 작업을 줄이고, 더 빠르게 서비스를 릴리스할 수 있다.
==버그 조기 발견==
→ 코드 변경 시 자동으로 ==테스트==가 실행되므로, 오류나 버그를 초기에 발견하고 빠르게 수정할 수 있다.
협업 효율성 향상
→ 여러 개발자가 동시에 작업해도 변경사항을 자주 통합하고 자동으로 검증하므로 충돌을 줄이고 협업이 쉬워진다.
품질 향상
→ 자동화된 ==테스트==와 코드 검사 덕분에 코드 품질이 높아지고, 운영 환경에서 발생하는 문제를 줄일 수 있다.
==짧은 릴리스 주기==
→ 작은 단위의 변경 사항도 안정적으로 자주 ==배포==할 수 있어, 빠른 피드백 수집과 대응이 가능하다.

</details>
