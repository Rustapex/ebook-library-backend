[ABC 전자책 대여 플랫폼 최종 시연 시나리오]

────────────────────────────────────
시연 계정 사용 원칙
────────────────────────────────────

1. 회원가입 계정
- 회원가입과 로그인 성공만 확인하는 신규 더미 계정
- 쿠폰·포인트·출석·대여 등 본 시연에는 사용하지 않음

2. 본 시연 계정
- DB에 미리 존재하는 시연용 USER 계정
- 쿠폰·포인트·출석·대여·결제·알림 데이터가 준비된 계정

3. 관리자 계정
- USER 시연 종료 후 관리자 기능 확인에 사용

연습 계정:
- 1회차: abc_demo_user01
- 2회차: abc_demo_user02
- 3회차: abc_demo_user03
- 4회차: abc_demo_user04
- 최종 발표: abc_demo_user05

회원가입은 최종 발표에서 한 번만 실제 완료한다.
연습 때는 회원가입 입력과 중복 확인까지만 연습하고 최종 가입 버튼은 누르지 않는다.

관리자 EPUB 업로드도 연습 때는 확인창에서 취소하고 최종 발표에서만 실제 완료한다.

1. 회원가입 및 로그인
======================================================================

사용 화면:
- 회원가입 U-002 `/signup`
- 로그인 U-003 `/login`

1-1. 회원가입 화면 접속

- 메인 화면 우측 상단의 회원가입 버튼 클릭
- `/signup` 화면으로 이동
- 회원가입 입력 항목 전체 확인

1-2. 아이디 중복 확인 실패

- DB에 이미 존재하는 중복 확인용 아이디 입력
- 아이디 중복 확인 버튼 클릭
- 이미 사용 중인 아이디라는 안내 확인
- 회원가입이 진행되지 않는 것 확인

1-3. 사용 가능한 아이디 확인

- 발표용으로 준비된 미사용 아이디 입력
- 아이디 중복 확인 버튼 클릭
- 사용 가능한 아이디라는 안내 확인

1-4. 신규 회원가입

- 비밀번호와 비밀번호 확인 입력
- 이름 입력
- 미사용 이메일 입력
- 연락처 입력
- 생년월일 입력
- 필요한 회원가입 항목 입력
- 회원가입 버튼 클릭
- 회원가입 성공 안내 확인
- 로그인 화면으로 이동

1-5. 신규 더미 계정 로그인

- 방금 가입한 아이디 입력
- 비밀번호 입력
- 로그인 버튼 클릭
- 로그인 성공 확인
- 메인페이지로 이동하는 것 확인

여기까지가 신규 회원가입 계정의 역할이다.

1-6. 신규 더미 계정 로그아웃

- 사용자 메뉴 열기
- 로그아웃 클릭
- 비회원 상태 또는 로그인 화면으로 이동하는 것 확인

1-7. 기존 본 시연 계정으로 로그인

- `/login` 이동
- 해당 회차에 사용할 기존 USER 계정 입력
- 최종 발표에서는 `abc_demo_user05` 사용
- 로그인 성공
- 메인페이지로 이동

이후 모든 사용자 기능은 이 기존 USER 계정으로 진행한다.

2. 메인페이지 및 컬렉션
======================================================================

사용 화면:
- 홈 U-001 `/`
- 도서 목록 U-006 `/books`
- 컬렉션 결과 `/books?section=collection&collectionId={collectionId}&source=home`

2-1. 메인페이지 전체 확인

- 상단 헤더와 메뉴 확인
- 메인 배너 확인
- 추천 도서 영역 확인
- 컬렉션 영역 확인
- 공지사항 영역 확인
- 페이지를 아래로 천천히 스크롤
- 메인페이지에 구성된 주요 영역 전체 확인

검색·베스트 기능은 이번 시연에서 제외한다.

2-2. 시리즈 컬렉션 확인

- 메인페이지의 시리즈 컬렉션 확인
- 예: “Why? 시리즈 모아보기”
- 컬렉션에 여러 도서가 노출되는 것 확인
- 더보기 클릭
- 컬렉션 도서 목록 화면으로 이동
- 컬렉션 제목과 연결 도서 확인
- 도서 배치 순서 확인

2-3. 할인 컬렉션 확인

- 메인페이지로 돌아가기
- 할인 또는 이벤트 컬렉션 확인
- 예: “파이썬 입문 할인전”
- 할인율 표시 확인
- 더보기 클릭
- 할인 컬렉션 도서 목록 확인
- “나도코딩의 파이썬 입문”이 포함되어 있다면 해당 도서 확인

3. 사용자 공지사항
======================================================================

사용 화면:
- 공지 목록 `/notices`
- 공지 상세 `/notices/:noticeId`

3-1. 공지 목록 이동

- 메인페이지 공지사항 영역 확인
- 공지사항 더보기 또는 공지 메뉴 클릭
- `/notices` 이동

3-2. 공지 목록 확인

- 공지가 5개 이상 표시되는 것 확인
- 공지 제목과 작성일 확인
- 서비스 안내, 점검, 도서, 이벤트 등 여러 유형 확인
- 사용자 화면에는 ACTIVE 공지만 노출되는 것 확인

3-3. 공지 상세 확인

- 가장 최근 공지 클릭
- 공지 제목과 본문 확인
- 이전글·다음글 이동 영역 확인
- 이전글 또는 다음글 한 번 클릭
- 다른 공지 상세로 정상 이동하는 것 확인

4. 출석체크
======================================================================

사용 화면:
- 출석 `/me/attendance`

4-1. 출석 화면 이동

- 마이페이지 메뉴 열기
- 출석체크 클릭
- `/me/attendance` 이동

4-2. 기존 출석 확인

- 최근 6일 동안 연속으로 출석된 상태 확인
- 시연 당일은 아직 출석되지 않은 상태 확인
- 연속 출석 일수가 6일로 표시되는지 확인

4-3. 당일 출석

- 출석체크 버튼 클릭
- 출석 성공 안내 확인
- 시연 당일 출석 상태로 변경되는 것 확인
- 연속 출석 일수가 7일로 변경되는 것 확인

주의:
- 출석으로 쿠폰이 자동 지급된다고 설명하지 않음
- 챌린지 화면과 챌린지 보상은 시연하지 않음
- 쿠폰은 기존 보유 쿠폰으로 별도 확인

8. 도서 대여 및 결제
======================================================================

사용 화면:
- 대여·결제 U-009 `/books/:bookId/rent`
- 결제 완료 `/books/:bookId/rent/complete`

8-1. 대여 진행

- 나도코딩 도서 상세에서 대여 또는 결제 버튼 클릭
- 대여·결제 화면 이동
- 도서명과 기본 가격 확인

8-2. 쿠폰 적용

- 사용 가능한 쿠폰 목록 열기
- 앞서 확인한 할인 쿠폰 선택
- 쿠폰 할인 금액 반영 확인

예:
- 도서 가격 5,000원
- 쿠폰 할인 500원

8-3. 포인트 적용

- 포인트 사용 입력란에 1,000포인트 입력
- 보유 포인트보다 큰 금액이 아닌지 확인
- 포인트 할인 반영 확인

예상 최종 금액:
- 기본 금액 5,000원
- 쿠폰 할인 500원
- 포인트 사용 1,000원
- 최종 결제 금액 3,500원

8-4. 결제 완료

- 최종 결제 금액 확인
- 결제 버튼 클릭
- 결제 완료 화면 이동
- 결제 성공 안내 확인
- 대여 정보 또는 결제 번호가 있다면 확인

10. EPUB 뷰어
======================================================================

사용 화면:
- 뷰어 U-011 `/rentals/:rentalId/read`

10-1. 뷰어 진입

- 결제 완료 화면 또는 내 서재에서 읽기 버튼 클릭
- 뷰어로 이동
- EPUB 본문이 정상적으로 열리는지 확인
- 첫 위치에서 시작하는지 확인

10-2. 기본 보기 설정 확인

초기값:
- 글자 크기 100%
- 페이지 넘김 방식 PAGE

- 현재 글자 크기 확인
- 현재 보기 방식 확인
- 다음 페이지 버튼으로 여러 페이지 이동

10-3. 처음으로 이동

- 처음 버튼 클릭
- EPUB 첫 위치로 이동하는지 확인

10-4. 목차 이동

- 목차 메뉴 열기
- 목차 항목 확인
- 중간 장 또는 특정 목차 항목 클릭
- 선택한 목차 위치로 이동하는지 확인

10-5. 보기 설정 변경

- 보기 설정 열기
- 글자 크기를 100%에서 140%로 변경
- 본문 글자가 커지는 것 확인
- 페이지 넘김 방식을 PAGE에서 SCROLL로 변경
- 세로 스크롤 방식으로 변경되는 것 확인
- 변경된 상태로 본문을 조금 더 읽기

11. 북마크와 마지막 위치 저장
======================================================================

사용 화면:
- 동일 뷰어 `/rentals/:rentalId/read`

11-1. 북마크 4개 생성

- 서로 다른 네 위치로 이동
- 각 위치에서 북마크 추가
- 총 4개의 북마크 생성
- 북마크 추가 성공 상태 확인

같은 위치를 중복 북마크하지 않는다.

11-2. 북마크 목록 확인

- 북마크 목록 열기
- 생성한 북마크 4개가 표시되는지 확인
- 각 북마크의 위치 또는 제목 확인

11-3. 북마크 위치로 이동

- 두 번째 또는 세 번째 북마크 선택
- 해당 위치로 이동하는지 확인

11-4. 마지막 위치 변경

- 북마크 위치로 이동한 뒤 본문을 조금 더 읽기
- 마지막으로 읽은 위치가 북마크 위치보다 뒤가 되도록 이동
- 뷰어 종료

11-5. 뷰어 재진입

- 내 서재로 이동
- 방금 대여한 도서의 이어보기 클릭
- 뷰어 재진입
- 처음 페이지가 아니라 마지막으로 읽었던 위치에서 열리는지 확인

- DB 관리자가 전달한 EPUB 미등록 기존 도서 bookId 확인

22-2. 대상 도서 입력

- EPUB 미등록 기존 도서 bookId 입력
- 신규 도서가 아니라 기존 도서인지 확인

22-3. EPUB 파일 선택

- 전달받은 테스트용 EPUB 선택
- 파일명이 표시되는지 확인
- 파일 크기가 50MB 이하인지 확인

22-4. 업로드 확인창

- EPUB 업로드 버튼 클릭
- 대상 bookId 확인
- 선택한 파일명 확인
- 기존 사용자 데이터에 대한 경고 문구 확인

연습 1~4회차:
- 확인창까지만 열기
- 취소 클릭
- 실제 업로드하지 않음

최종 발표:
- 영향 확인 후 업로드 버튼 클릭
- EPUB 업로드 성공 안내 확인
- EPUB version 1 확인
