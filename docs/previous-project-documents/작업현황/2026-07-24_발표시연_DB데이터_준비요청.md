## 기본 정보

- 시연 예정일: `[YYYY-MM-DD]`
- 대상 DB: `[시연 DB명]`

## 중요 요청사항

- 회원가입 계정은 기능 확인용 신규 더미 계정입니다.
- 실제 사용자 기능 시연은 데이터가 미리 준비된 기존 USER 계정으로 진행합니다.
- 기존 USER 계정에 사전 이어보기 데이터는 필요하지 않습니다.
- 이어보기는 발표 중 새로 대여하고 읽은 도서의 독서 진행률을 사용합니다.
- 복구·원복·초기화 SQL은 요청하지 않습니다.
- 기존 데이터 삭제나 변경을 최소화하고 시연 전용 데이터를 추가해주세요.
- 검색·베스트 전용 데이터 조정은 요청하지 않습니다.
- 신규 도서는 가급적 생성하지 않고 기존 도서를 활용해주세요.
- 관리자 도서관 신규 등록은 시연하지 않습니다.
- 사용자 도서관 위치정보 조회에 필요한 데이터는 준비해주세요.
- 완료 후 시연에 사용할 계정과 주요 ID만 회신해주세요.
- 비밀번호 평문은 공용 SQL이나 문서에 넣지 말고 별도로 전달해주세요.

## 2. 본 시연용 기존 USER 계정 5개

권장 `login_id`:

- `abc_demo_user01`
- `abc_demo_user02`
- `abc_demo_user03`
- `abc_demo_user04`
- `abc_demo_user05`

사용 목적:

- `user01`: 연습 1회차
- `user02`: 연습 2회차
- `user03`: 연습 3회차
- `user04`: 연습 4회차
- `user05`: 최종 발표

공통 조건:

- `role`: `USER`
- `status`: `JOINED`
- 정상 로그인 가능
- 제재 상태가 아님
- `login_id`, 이메일, 연락처는 서로 다름
- 동일한 회원 등급
- 동일한 시연 데이터 조건

### 2.1 포인트

- `point_balance` 최소 1,000포인트 이상
- 권장 잔액 3,000포인트
- `point_history`와 현재 잔액 일치
- 신규 결제에 1,000포인트 사용 가능

### 2.2 쿠폰

- 결제에 사용할 수 있는 쿠폰 최소 1개
- 권장: 10% 할인 쿠폰
- 쿠폰 상태 `ACTIVE`
- 회원 쿠폰 상태 `ISSUED`
- 시연일 이후까지 유효
- 아직 사용하지 않은 상태

### 2.3 출석

- 시연일 직전 6일 연속 출석
- 시연 당일 출석 데이터 없음
- 시연 중 당일 출석 가능
- 당일 출석 후 연속 출석 7일 표시 가능

### 2.4 기존 내 서재

- 기존 대여 도서 여러 권
- 목록을 스크롤할 수 있을 정도의 데이터
- `READY`, `READING`, `OWNED` 또는 현재 서비스의 유효한 상태가 섞여 있음
- 완독 도서 최소 1권

사전 이어보기용 `reading_progress`는 준비하지 않아도 됩니다. 발표 중 나도코딩 도서를 대여하고 읽어서 생성되는 진행률을 이어보기 시연에 사용합니다.

### 2.5 기존 알림

- 기존 알림 여러 건
- 읽음·안 읽음 상태 혼합
- 발표 중 신규 대여·결제 알림이 최신으로 추가될 수 있어야 함

### 2.6 기존 결제내역

- 성공 결제 최소 2건
- 결제일이 서로 다름
- 쿠폰 사용 결제 1건
- 포인트 사용 결제 1건
- `payment`와 `book_rental` 관계 정상

### 2.7 기존 신고내역

- 기존 신고내역 1건 정도
- 발표 중 신고할 Why 도서와 나도코딩 리뷰에 대한 기존 신고는 없음

### 2.8 프로필

- 이름, 이메일, 연락처 존재
- 이메일과 연락처가 다른 회원과 중복되지 않음
- 프로필 수정 가능
- 비밀번호 변경 가능

### 2.9 희망 도서 신청 내역

- 각 USER 계정에 기존 희망 도서 신청 내역 최소 1건
- 도서명 존재
- 신청 상태가 화면에 표시 가능
- 가능하면 계정별로 `REQUESTED` 또는 `IN_REVIEW` 상태 포함

## 9. 챌린지

챌린지 기능은 시나리오 틀에는 유지하지만 현재 구현 문제로 실제 시연에서 제외될 수 있습니다.

데이터 준비가 가능하다면:

- `ACTIVE` DAILY 챌린지 최소 1개
- `ACTIVE` TOTAL 챌린지 최소 1개
- 출석 관련 챌린지
- 대여 관련 챌린지
- 리뷰 관련 챌린지

다만 DB 데이터만으로 행동 연동과 프론트 표시 문제를 해결할 수 없으므로, 챌린지 보상 수령을 최종 시연 필수 조건으로 보지 않습니다.

- 표지 URL과 설명 존재
- 외부 분류명 존재

EPUB 보유 기존 도서 1권:

- 사용자 뷰어 시연용
- 나도코딩 도서 사용 권장
- 유효한 `book_epub` 존재
- 발표 중 교체하지 않음

EPUB 미등록 기존 도서 1권:

- 신규 도서가 아닌 기존 도서
- 발표 시작 전 `book_epub` 없음
- 관리자 화면에서 검색 가능
- 다른 사용자의 대여·진행률·북마크 없음
- 관리자 EPUB 업로드 시연용

업로드용 EPUB:

- 유효한 `.epub`
- 50MB 이하
- DRM·암호화 없음
- 도서명과 EPUB 내용이 일치하지 않아도 됨
- 발표 PC에서 선택할 수 있도록 파일 전달

연습:

- 확인창까지만 진행하고 취소

최종 발표:

- 실제 EPUB 업로드
- 업로드 성공 및 version 확인

## 13. 최종 회신 요청

### 계정
